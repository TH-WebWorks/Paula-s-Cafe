# Paula's Cafe

A neighborhood lunch counter site for Paula's Cafe in Valley Junction, West Des Moines.

Built with [Next.js](https://nextjs.org/) and [Tailwind CSS](https://tailwindcss.com/).

## Prerequisites

- Node.js `>=20.9.0`

## Local development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Deploy to Vercel

1. Push this repo to GitHub.
2. Import the project in [Vercel](https://vercel.com/new).
3. Vercel will detect Next.js automatically — no extra configuration needed.

Optional: set `VERCEL_URL` is handled automatically on Vercel. For a custom domain, add it in the Vercel project settings.

## Scripts

- `npm run dev` — start the development server
- `npm run build` — create a production build
- `npm run start` — serve the production build locally
- `npm test` — build and run smoke tests
- `npm run lint` — run ESLint
